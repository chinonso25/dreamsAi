# The Dreamer App Store metadata

Four English localisations prepared using Kronop/vibe-aso on 8 October 2026. App Store ID: 6740153274. Proposed name and subtitle were chosen by the owner in this chat.

- Name: Dream Journal: The Dreamer
- Subtitle: Voice Diary & AI Summaries
- Locales: en-US, en-GB, en-CA, en-AU

The text targets the current source and the 1.0.4 draft. It must travel with a binary that implements those features. The live 1.0.3 binary was not retested as part of this task.

`reports/aso/asc-verification.json` records confirmed App Store Connect readbacks when the save succeeds. These files use fastlane's standard field names. Credentials remain outside this repository. No automatic upload command, binary submission, price change or screenshot overwrite is configured here.

The four metadata sets intentionally share the same keyword concepts; UK/Australian prose uses organise/favourites/cancelled. Support, privacy and marketing URLs point to the English site in every locale. Release notes describe source features and still need matching build verification before release.

Keyword choices use relevance and four-storefront Apple Search API snapshots. Search volume, keyword difficulty, device ranking and conversion uplift have not been measured.
