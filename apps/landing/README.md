# The Dreamer landing site

Static, accessible marketing site for the iPhone app. Published to **https://thedreamer.app**, with `www.thedreamer.app` redirected to the apex. The landing Worker is separate from `thedreamer-api` and has no database, audio, email, or AI bindings.

## Edit, preview, deploy

Requires Bun 1.4.2 and Node 24. Wrangler is declared directly in this workspace;
install dependencies once from the repository root.

```sh
bun install --frozen-lockfile
bun run check:landing
bun run dev:landing
# Local preview: http://localhost:8788

# To deploy, from the repository root:
cd apps/landing
bun run deploy
```

Page copy, FAQs, structured data, navigation and SEO files are generated by `scripts/build.mjs`. Design is in `assets/style.css`. Update the `updated` date when making substantive content changes. Generated `dist/` and local Wrangler state are ignored. Optimized images and local Outfit fonts are checked-in assets; their original sources remain in the Expo app's assets and font package.

## Published pages

- `/`: Landing page with direct App Store download links and seven native HTML FAQ disclosures.
- `/about`: Publisher, app/brand identity, purchase terms, privacy and support.
- `/privacy`, `/terms`: App-specific privacy and service terms.
- `/support`, `/contact`: Troubleshooting, corporate email and postal address.
- `/subscriptions`, `/delete-account`: Billing and deletion guides.
- `/guides/how-to-keep-a-dream-journal`: Practical first-entry guide.
- `/guides/dream-journal-prompts`: Twelve reflection prompts.
- `/download`: Redirect to the verified App Store ID `6740153274`.
- `/robots.txt`, `/sitemap.xml`, `/llms.txt`: Crawl and discovery information.

## Search and AI discovery

Every page contains complete HTML content, a unique title and description, a canonical URL, social card metadata, an Apple Smart App Banner and JSON-LD. The structured-data graph describes the publisher, website and iOS app. Guides add Article and BreadcrumbList markup; the homepage FAQ schema matches the visible questions and answers. No fabricated reviews, ratings, prices or medical claims.

`llms.txt` is an optional discovery aid, not a Google requirement or a ranking promise. Google requires the same useful content and crawlability for AI features as for ordinary search. FAQ markup does not establish eligibility for a Google FAQ rich result. The page has no runtime JavaScript, external font requests, trackers or form submissions.

On the App Store, the product is **Dream Journal: Dream AI** by **LEVITES TECH LTD**. The website clearly explains its relationship to The Dreamer brand. Product mockups are labelled illustrative, avoiding a claim that a new UI is already the installed App Store version. App pricing is deferred to the real in-app/Apple purchase surface. The app-specific privacy policy is hosted at `/privacy`; `/terms` links to Apple’s standard EULA. Support uses the publisher’s existing corporate email. See `APP_STORE_SETUP.md` for store fields and remaining app-review work.

## After launch

1. Verify domain ownership in Google Search Console and Bing Webmaster Tools and submit `https://thedreamer.app/sitemap.xml`.
2. Use URL Inspection to request indexing of the homepage and useful guides. Publishing alone does not prove indexing or ranking.
3. Measure organic traffic and App Store conversions; there is no pre-launch baseline or claimed improvement.
4. Check Cloudflare bot controls if real crawler logs show blocked requests. User-agent response checks do not certify access from a vendor's actual IP ranges.
5. Keep the App Store name, publisher, pricing, privacy and website descriptions consistent as future app versions ship.
